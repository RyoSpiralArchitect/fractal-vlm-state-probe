# Research Note 0045: Padding Policy And Explicit Marginals

Date: 2026-10-07

Status: registered input experiment; new padding comparisons not yet measured.

[Note 0044](0044_all_cell_frequency_control_feasibility.md) showed a large gap
between raw and actual-processor frequency matching. The
[registered padding comparison](../pairing_validation_protocol.md#stage-4b-padding-policy-comparison)
crosses fixed original, prior low-pass and common-permutation content with
black, fixed-gray and palette-mean padding. All 32 blocks remain in each cell
of this crossed design.

The image content occupies 75% of the square canvas. Its remaining 25% adds
an explicitly registered RGB point mass. Input acceptance, changed marginals,
pixel-sham identity and non-pixel processor metadata are separate measurements.
This experiment is input-only; model-cache calibration remains a later gate.
